# Проект «Сложно сосредоточиться»
## О проекте
Практическая работа направлена на закрепление теории по адаптивности и графике. В этом проекте я научилась использовать CSS-переменные, новые единицы измерения и функции, потренировалась в создании резиновой вёрстки с подходом Mobile First, а также поработала с медиазапросами и переключениями цветовых тем.

## Инструкция по использованию
1. Выберите предпочтительную цветовую тему:
* день — светлая тема в розовых оттенках;
* авто — тема подстроится под настройки вашего устройства/браузера;
* неон — тёмная тема в синем, фиолетовом и ярко-розовом цвете.
2. Используйте скролл вниз для навигации по странице.
3. В некоторых абзацах есть отдельные слова со ссылками на внешние ресурсы — они выделены цветной тенью. Если нажать на ссылку, ресурс откроется в новой вкладке.

##  Системные требования
Для просмотра и взаимодействия с сайтом подойдёт следующий набор инструментов:
* десктопное или мобильное устройство: ПК, ноутбук, планшет, смартфон;
* любой современный браузер: Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari, Яндекс Браузер;
* операционная система: Windows, macOS, Linux, iOS, Android;
* доступ к интернету.
